# 💳 Credit Risk Classification | Machine Learning Project

I’m excited to share my latest Machine Learning project: Credit Risk Classification, where I developed an end-to-end workflow to predict whether a credit applicant is classified as Good or Bad Credit Risk.

📊 Project Overview

Using the South German Credit Dataset, I explored financial and personal characteristics of credit applicants and built a Logistic Regression model for binary classification.

🔍 Key steps:

Conducted Exploratory Data Analysis (EDA) to understand data distribution, missing values, and feature relationships
Performed data preprocessing for numerical and categorical features
Developed a Logistic Regression classification model using a preprocessing pipeline
Evaluated the model using Accuracy, Precision, Recall, F1-Score, Confusion Matrix, and ROC-AUC
Saved the trained model using Joblib
Built an interactive Streamlit application for real-time credit risk prediction

🛠️ Tech Stack:
Python | Pandas | NumPy | Scikit-learn | Matplotlib | Seaborn | Joblib | Streamlit

🎯 The final application allows users to:

Input applicant information
Generate a Good / Bad Credit Risk prediction
View the probability of each prediction
Explore the dataset and model performance through an interactive dashboard

This project gave me hands-on experience in applying the end-to-end Machine Learning workflow, from understanding raw data to deploying a model into an interactive application.
